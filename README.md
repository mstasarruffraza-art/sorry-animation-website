# 🎨 Sorry Animation Website

A beautiful, colorful animated website with a cute animated "Sorry" sticker and interactive slides.

## ✨ Features

- **Animated Sorry Sticker** - Floating, pulsing animated sticker with a sad emoji face and falling tears
- **Colorful Slides** - 5 different slides with vibrant gradient backgrounds
- **Smooth Animations** - Floating sticker, heart animations, and text transitions
- **Interactive Navigation** - Previous/Next buttons and slide indicators
- **Auto-play** - Slides automatically change every 5 seconds
- **Keyboard Support** - Use arrow keys to navigate slides
- **Responsive Design** - Works perfectly on mobile and desktop
- **Gradient Background** - Continuously shifting colorful background

## 📁 Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Slide navigation functionality
- `README.md` - This file

## 🚀 How to Use

1. Clone this repository
2. Open `index.html` in your browser
3. Navigate through slides using:
   - Previous/Next buttons
   - Dot indicators
   - Arrow keys on keyboard
   - Auto-play (automatic every 5 seconds)

## 🎯 Slide Contents

1. **I'm Truly Sorry** - Purple gradient
2. **I Regret My Actions** - Pink/Red gradient
3. **You Mean the World to Me** - Blue gradient
4. **Let's Start Fresh** - Cyan/Green gradient
5. **I Promise to Do Better** - Orange/Yellow gradient

## 🎨 Customization

### Change Colors
Edit the gradient colors in `index.html` within the slide-content divs:
```html
style="background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);"
```

### Change Messages
Modify the `<h1>` and `<p>` text in the slides

### Adjust Animation Speed
In `styles.css`, modify the animation duration values (e.g., `3s` for 3 seconds)
